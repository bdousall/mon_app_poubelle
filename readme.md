# 🗑️ Détection Intelligente de Poubelles

Application de détection IA pour identifier si une poubelle est pleine ou vide.

## 🚀 Déploiement

Cette application est déployée sur Streamlit Community Cloud.

## 📁 Structure

- `app.py` - Application principale
- `requirements.txt` - Dépendances Python
- `best.pt` - Modèle YOLO par défaut (optionnel)

## 🛠️ Utilisation

1. Uploader un modèle YOLO (.pt) ou utiliser le modèle par défaut
2. Uploader une image contenant une poubelle
3. Lancer l'analyse
4. Visualiser les résultats
